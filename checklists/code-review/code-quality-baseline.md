# 代码质量基线子清单

适用范围：所有发生代码、配置或脚本写入的任务。

## 变更范围与可追溯性

- [ ] 变更目标、入口点、完整调用链和业务影响范围明确。
- [ ] 修改的文件、模块和依赖项可追溯；涉及跨模块变更时确认所有相关位置。
- [ ] 验证命令、测试用例、通过项、失败项和未覆盖项可追溯。
- [ ] 新增变更是否需更新文档、API 契约、配置示例或发布说明。

## 空值与边界处理

- [ ] 检查空值、null、空集合、空字符串和默认值的处理逻辑。
- [ ] 边界值（最小值、最大值、0、-1、长度限制）的处理是否明确。
- [ ] 重复调用、幂等性和快速连续触发是否有明确语义。
- [ ] 输入验证是否防止溢出、负数、过长字符串或不合法格式。

## 错误处理与异常

- [ ] 异常分为可恢复和不可恢复两类，可恢复异常有重试或降级方案。
- [ ] 异常链完整，保留根因和上下文信息，不丢失原始堆栈。
- [ ] 对外错误响应不暴露内部堆栈、SQL、密钥、内部路径或实现细节。
- [ ] 日志记录异常时包含业务上下文、参数脱敏、重复异常限流。
- [ ] 空指针、类型转换、越界和网络异常等常见异常有明确处理。

## 资源管理与生命周期

- [ ] 文件、数据库连接、网络连接、线程和临时文件在成功与失败路径都能释放。
- [ ] 使用 try-with-resources、try-finally 或显式关闭，避免资源泄漏。
- [ ] 定时器、监听器、订阅和缓存在组件销毁时正确注销。
- [ ] 流式处理不需要全量加载，批量操作控制内存和超时。
- [ ] 长连接、连接池和后台线程不导致资源耗尽或无限增长。

## 日志与可观测性

- [ ] 关键操作记录业务操作、入参、结果、耗时和用户身份。
- [ ] 日志不记录敏感信息（密码、Token、个人数据、密钥）。
- [ ] 日志不输出无界大对象、序列化对象或过长字符串。
- [ ] 异常日志包含定位问题所需的文件、行号、入参和状态。
- [ ] 日志级别合理，生产环境避免 DEBUG 级别过多导致性能下降。

## 代码注释与文档

- [ ] 新增注释说明业务原因、设计考虑或非显而易见的约束。
- [ ] 注释不重复代码表面行为，避免"i++ 将 i 加 1"这样无信息量的注释。
- [ ] 复杂算法、边界条件、兼容性处理和性能优化有必要的说明。
- [ ] 公共接口有说明参数、返回值、异常和使用示例的文档。

## 交叉参考

- [ ] Java 代码另参考 java-quality.md 的命名、集合、并发和性能要求。
- [ ] Spring Boot 代码另参考 springboot-quality.md 的配置、事务和生命周期。
- [ ] 数据库交互另参考 data-access-quality.md 的参数绑定、事务和映射。
- [ ] 安全敏感代码另参考 security-code-quality.md 的输入、认证和授权。
