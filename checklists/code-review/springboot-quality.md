# Spring Boot 质量子清单

适用范围：Spring Boot Bean、Web 接口、配置、事务、缓存、消息和运行生命周期。

## Bean 与依赖注入

- [ ] 构造器注入优于字段注入，确保依赖明确和可测试。
- [ ] Bean 作用域（Singleton、Prototype、Request 等）是否与业务语义一致。
- [ ] 条件装配（@ConditionalOnProperty、@ConditionalOnClass）是否正确应用于不同环境。
- [ ] 循环依赖问题是否通过重构或延迟注入解决。
- [ ] 代理边界问题：`@Async`、`@Scheduled`、`@Transactional` 在代理有效范围内使用。

## Web 接口与参数校验

- [ ] HTTP 方法（GET/POST/PUT/DELETE）是否符合 RESTful 约定。
- [ ] 状态码（200/201/400/404/500）是否准确反映业务结果。
- [ ] 请求/响应 DTO 是否完整定义，避免与实体混用导致序列化问题。
- [ ] 必填字段、长度、格式、范围、枚举使用 JSR 303/380（@NotNull、@Valid 等）。
- [ ] 校验异常在进入业务或持久化层前捕获并统一处理。

## 错误处理与统一异常

- [ ] 全局异常处理器（@ControllerAdvice）统一格式，不向客户端暴露堆栈、SQL、密钥。
- [ ] 业务异常与系统异常分类，返回不同状态码和错误信息。
- [ ] 重复提交、幂等请求、超时和客户端断开有明确处理。
- [ ] 大请求体、文件上传有大小限制和安全校验。

## 事务与业务一致性

- [ ] 事务边界覆盖完整业务操作，不把关键写入拆到独立事务。
- [ ] @Transactional 注解因自调用、私有方法、异常类型或代理失效而无效时需改进。
- [ ] 回滚条件明确：checked 异常默认不回滚，需明确指定 rollbackFor。
- [ ] 只读事务（readOnly=true）用于查询优化，传播级别（Propagation）符合业务要求。
- [ ] 跨服务、异步任务、事件发布不能假设本地事务自动覆盖。

## 并发与幂等

- [ ] 写入成功、缓存更新、消息发送和外部接口调用失败时，数据状态可恢复。
- [ ] 乐观锁、唯一约束或幂等键防止重复提交和重复写入。
- [ ] 并发修改导致写入失败时有重试或用户提示。

## 配置与环境管理

- [ ] 配置前缀、类型转换、默认值和环境覆盖逻辑明确。
- [ ] 不同环境（开发、测试、生产）的数据库、消息、外部服务配置隔离。
- [ ] 禁止在代码和配置库中硬编码密钥、Token、密码；使用密钥管理系统。
- [ ] Profile 和条件配置是否可能导致生产环境加载错误实现。
- [ ] 缺失配置时启动行为是否明确，是否报告或降级。

## 版本与依赖兼容

- [ ] Spring Boot、Starter 和第三方依赖版本是否存在冲突或不兼容升级。
- [ ] 依赖废弃特性、breaking changes 和升级时的兼容顺序。
- [ ] 生产环境使用的依赖版本是否经过充分测试。

## 缓存策略

- [ ] 缓存 key 生成逻辑、过期时间、更新和失效策略是否符合业务一致性。
- [ ] 缓存穿透（热点 key 不存在）、击穿（大量请求同时过期）、雪崩（大量 key 同时过期）的应对措施。
- [ ] 脏数据、缓存与数据库不一致时的处理和预防。

## 消息与外部依赖

- [ ] 消息生产和消费处理重复、乱序、失败、重试、死信和幂等。
- [ ] 消费进度、消费异常和恢复路径是否可观测。
- [ ] HTTP/RPC 客户端配置连接超时、读取超时、连接池、重试上限和熔断/降级。
- [ ] 重试仅用于可安全重试的错误，避免放大流量或造成重复写入。

## 可观测性与运行安全

- [ ] 健康检查、就绪检查和启动完成信号是否准确反映应用状态。
- [ ] 关键业务日志、请求标识、审计信息是否足够定位问题和审计。
- [ ] 日志、Actuator、错误页、调试配置在生产环境是否暴露内部信息。
- [ ] 优雅停机是否等待请求、消息、后台任务完成并释放线程池、连接池资源。
- [ ] 启动、关闭、线程池和连接池释放是否可观察且可恢复。

## 框架行为验证

- [ ] 框架行为结论必须通过启动日志、接口调用、日志输出或测试验证。
- [ ] 不能只凭注解名称推断（如 @Transactional 不一定生效）。
- [ ] 配置修改后验证启动日志和实际行为是否符合预期。

## 常见陷阱与交叉参考

- [ ] 避免在 @PostConstruct 中进行昂贵操作导致启动卡顿。
- [ ] 谨防字段注入导致代理边界问题或循环依赖。
- [ ] 参考 code-quality-baseline.md 的异常处理、资源管理和日志要求。
- [ ] 参考 java-quality.md 的集合、并发和线程池要求。
- [ ] 涉及数据访问参考 data-access-quality.md；安全参考 security-code-quality.md。
