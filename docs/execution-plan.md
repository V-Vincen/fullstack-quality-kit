~~~text

    ↓

    ↓
27 个领域子清单
    ↓
fullstack-review 主 skill
    ↓
7 个专业子 skill
    ↓
5 个按需工作流
    ↓
安装、安全升级、状态、验证和全局卸载脚本
~~~

1. 项目级使用：将 `.codex/skills/` 和 `.codex/checklists/` 安装到业务项目。
2. 全局使用：将 `fullstack-review` 和命名空间清单安装到用户全局目录，并按需合并全局规则管理区块。

### 第 5 步：编写安装、卸载和验证脚本

目标：让其他使用者 clone 仓库后可以按说明完成安装、升级和验证。

脚本职责：

- `validate.sh`：检查 skill、工作流、清单、规则、文档、引用、Unix 语法和 Windows 入口转发关系。
- `install-project.sh`：将 skills 和清单安装到指定业务项目，不覆盖已有的不同内容。
- `install-global.sh`：安装或安全升级全局 skills 和命名空间清单，按需合并规则管理区块；支持 `--skip-agents`。
- `uninstall-global.sh`：根据安装清单 v2，只删除内容仍与安装记录一致的受管理文件和规则区块。
- `status.sh`：显示源文件、项目级安装、全局安装和安装清单 v2 的一致、修改、缺失与异常状态。
- `validation-rules.conf`：统一维护 skill、工作流、总清单和领域子清单的预期数量。
- `.ps1`：提供 Windows 原生 PowerShell 入口，保持与 `.sh` 相同的安装、卸载、状态和验证行为。
- `.bat`：提供 Windows 命令提示符入口，只转发到对应的 `.ps1`，不维护第二套业务逻辑。

验收标准：

- 支持首次安装。
- 支持重复执行。
- 仅安全升级安装清单记录且未被用户修改的内容。
- 发现无安装记录、无法核验或用户已修改的冲突时停止。
- 已有等效全局规则时可以跳过规则区块合并。
- 支持卸载后恢复。
- 不执行目标不明确的删除。
- macOS/Linux 使用 `.sh`，Windows 使用 `.ps1` 或 `.bat`。

风险与回滚：

- 风险：安装脚本覆盖用户已有配置。
- 处理：默认不覆盖，冲突时停止并报告。
- 回滚：使用安装前备份恢复。

## 12. 术语注解

**skill**¹：Codex 可调用的专业能力说明目录。

**清单**²：触发某类任务后必须执行的检查项集合。

**全局规则**³：对所有项目生效的执行约束，例如授权、备份和验证要求。

**项目级配置**⁴：只在当前项目目录中生效的 skills、清单和规则。
