# 前端质量子清单

适用范围：HTML、CSS、JavaScript/TypeScript、React/Vue、页面组件和构建配置。

- [ ] 检查语义 HTML、表单标签、焦点顺序、键盘操作和动态内容可访问性。
- [ ] 检查响应式布局、长文本、空数据、滚动、层叠、遮挡和浏览器支持范围。
- [ ] 检查类型、可空值、异步异常、竞态、取消请求和组件销毁后的状态更新。
- [ ] 检查加载、成功、空数据、校验失败、权限不足、超时、网络失败和重试状态。
- [ ] 检查重复渲染、大列表、懒加载、资源尺寸、缓存和内存泄漏。
- [ ] 检查环境变量、构建产物、Source Map、依赖版本和发布配置是否泄露信息。
- [ ] 前端权限只作为体验控制，关键授权必须由后端再次校验。
