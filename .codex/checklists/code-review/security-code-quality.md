# 安全代码质量子清单

适用范围：认证、授权、输入处理、敏感数据、外部调用和安全配置代码。

- [ ] 每个读取、修改、删除、导出和下载入口都检查用户、组织、租户和资源归属。
- [ ] 检查 SQL、命令、模板、表达式、文件路径、URL 和反序列化输入。
- [ ] 检查 XSS、CSRF、SSRF、开放重定向、文件上传和资源耗尽风险。
- [ ] 检查 Token、Cookie、密码、密钥、证书和个人信息的存储、传递、日志和脱敏。
- [ ] 检查 CORS、SameSite、Origin、错误页、调试端点和管理端点暴露范围。
- [ ] 检查认证失败、暴力尝试、重放、频率限制和重复提交控制。
- [ ] 每个安全问题记录前置条件、入口、输入、授权判断、影响和回归验证。
