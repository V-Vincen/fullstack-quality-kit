# 数据访问质量子清单

适用范围：MyBatis、JPA/Hibernate、JDBC、查询构造器、Mapper、Repository 和 ORM 的数据访问实现。数据库引擎、DDL、索引和迁移问题另读 database-quality.md。

- [ ] 已确认实际访问框架、版本、数据库方言、分页方式、缓存策略、事务管理和测试工具。
- [ ] 用户输入、筛选条件、排序字段、表名和列名是否使用参数绑定或严格白名单校验。
- [ ] MyBatis 是否优先使用 `#{}` 参数绑定；`${}`、动态排序和 SQL 片段是否仅用于经过白名单校验的内容。
- [ ] JPA/JPQL、原生 SQL、JDBC 和查询构造器是否避免字符串拼接，并正确绑定空值、集合、枚举、时间和精度参数。
- [ ] 空集合、缺失条件、动态 `where` 和默认筛选是否可能扩大查询、更新或删除范围。
- [ ] Mapper 返回类型、字段别名、`resultMap`、类型处理器、枚举、JSON、时间、精度和空值映射是否准确。
- [ ] JPA/Hibernate 实体状态、脏检查、级联、孤儿删除、列默认值、实体关系和序列化边界是否符合业务规则。
- [ ] JDBC 的 `ResultSet`、连接、语句、事务和超时资源是否在成功与失败路径正确释放。
- [ ] 更新 0 行、更新多行、唯一约束冲突、乐观锁失败和部分批量失败是否有明确结果语义。
- [ ] 嵌套查询、延迟加载、关联集合和循环调用是否造成 N+1 查询、重复行、无界结果集或内存增长。
- [ ] 分页的主查询、总数查询、稳定排序、空页面、深分页和并发写入下的数据一致性是否正确。
- [ ] 批量插入、更新和删除是否控制批次、参数规模和事务大小，并能定位失败项、重试和回滚。
- [ ] 事务代理、传播行为、只读标记、异常回滚、Session、SqlSession、flush 和连接释放是否真实生效。
- [ ] 查询后再写入是否存在竞态；乐观锁、条件更新、唯一约束或幂等键是否真正生效。
- [ ] 租户、组织、用户、逻辑删除、数据权限和审计条件是否覆盖所有 Mapper 或 Repository 入口。
- [ ] SQL 参数、日志、异常和调试输出是否泄露密码、Token、个人信息或内部结构。
- [ ] 已明确接口、数据、状态、缓存、消息和回归验证结果，不能只验证方法调用成功或页面提示。
