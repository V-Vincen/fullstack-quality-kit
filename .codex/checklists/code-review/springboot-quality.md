# Spring Boot 质量子清单

适用范围：Spring Boot Bean、Web 接口、配置、事务、缓存、消息和运行生命周期。

- [ ] 检查构造器注入、Bean 作用域、条件装配、循环依赖和代理边界。
- [ ] 检查 HTTP 方法、状态码、请求响应模型、参数校验和统一错误处理。
- [ ] 检查事务是否因自调用、私有方法、异常类型或代理失效而不生效。
- [ ] 检查事务、缓存、消息、外部调用的成功、失败、重试、回滚和幂等关系。
- [ ] 检查环境配置、Profile、默认值、密钥、连接池、线程池和超时。
- [ ] 检查健康检查、日志、指标、调试端点、优雅停机和资源释放。
- [ ] 框架行为结论必须通过启动、接口、日志或测试验证，不能只凭注解名称推断。
