# Java 质量子清单

适用范围：Java 源码、Java 配置、公共模型和 Java 测试代码。

- [ ] 按项目采用的 Alibaba Java Coding Guidelines 版本检查命名、职责、常量、异常和集合使用。
- [ ] 检查 `equals`/`hashCode`、可变 Map key、比较器、类型转换、精度和时区。
- [ ] 检查集合容量、嵌套循环、批量处理、装箱拆箱和不必要的对象复制。
- [ ] 检查共享状态、可见性、锁顺序、死锁、线程安全集合和异步异常。
- [ ] 检查线程池大小、队列、拒绝策略、命名、关闭和阻塞调用。
- [ ] 检查流、文件、Socket、HTTP 响应体、连接和监听器的生命周期。
- [ ] 性能或 JVM 结论必须关联复杂度、基准、运行日志、堆转储或线程转储证据。
