# 数据库质量子清单

适用范围：关系型数据库的表结构、字段、约束、SQL、索引、事务、并发、迁移和回滚。适用于 MySQL、PostgreSQL、Oracle、SQL Server、SQLite 等实际使用的数据库引擎；不把某一引擎的语法或行为默认套用到其他引擎。

- [ ] 已确认数据库引擎、版本、驱动、字符集、排序规则、部署方式、数据量和迁移工具。
- [ ] 表、字段、主键、唯一约束、非空约束、默认值、外键、视图和触发器是否表达真实业务规则。
- [ ] 数值精度、金额、时间、时区、枚举、JSON、二进制、大文本、字符集和排序规则是否匹配实际数据。
- [ ] 新增或调整字段是否有字段注释；新建表是否为全部字段补充字段注释。
- [ ] SQL 的连接、空值、聚合、分组、排序、分页、重复行、边界日期和隐式类型转换是否正确。
- [ ] 更新和删除是否有明确条件、影响行数校验和误操作保护；空参数、空集合和缺失条件是否可能扩大范围。
- [ ] 索引列顺序是否匹配主要过滤、连接和排序；是否存在无效索引、函数包列、隐式转换、深分页和全表扫描。
- [ ] 性能结论是否有执行计划、真实数据量、统计信息、索引信息或可执行的补充验证方案。
- [ ] 事务边界、隔离级别、锁顺序、死锁重试、超时、长事务和大事务是否符合业务一致性要求。
- [ ] 库存、余额、额度和状态流转是否具备条件更新、版本控制、唯一约束或其他并发控制措施。
- [ ] 迁移是否说明执行前提、兼容顺序、历史数据处理、重复执行语义、锁影响、失败恢复和回滚限制。
- [ ] 大表回填、索引创建、数据修复和删除是否可分批、可暂停、可观测，并评估线上影响。
- [ ] 仅在实际使用对应引擎时，检查该引擎的方言、类型系统、锁行为、执行计划和在线变更能力。
- [ ] 数据库账号、网络访问、敏感字段、备份、审计、日志和错误信息是否符合最小权限与数据保护要求。
- [ ] 已明确验证命令、基线、预期结果、失败处理和不可逆变更的恢复限制。
