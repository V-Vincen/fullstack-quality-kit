# 用户流程验收子清单

适用范围：核心用户流程、关键页面、注册登录、提交申请、下单付款或用户明确要求体验验收的任务。

- [ ] 明确目标用户、核心任务、正常入口、测试环境、测试账号和未覆盖范围。
- [ ] 从普通用户可见的正常入口完成任务，不使用内部地址、源码、隐藏接口或开发者知识绕过步骤。
- [ ] 覆盖正常完成、失败、返回、刷新、中断和恢复等实际相关场景。
- [ ] 验证用户能否理解当前目标、发现正确入口、理解操作反馈并知道下一步。
- [ ] 结合实际浏览器渲染检查文字、控件、状态反馈、布局和必要的桌面端、移动端或目标浏览器表现；不能只凭自动化点击成功判定通过。
- [ ] 区分功能故障、体验障碍和视觉偏好；每个问题记录复现路径、证据、用户影响、最小改进方向和验证办法。
- [ ] 只使用已授权的测试环境、账号和测试数据；真实付款、对外发送、发布、删除或修改真实业务数据前停止并等待额外授权。
- [ ] 报告通过项、问题项、未验证范围、验证边界和已知风险。
