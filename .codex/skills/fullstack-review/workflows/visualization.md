# 关系图工作流

## 用途

将复杂的 Skill、清单、调用链和状态流转关系转换为可核验的图形化结果，帮助团队理解审查流程。

## 触发条件

- 用户明确要求画图。
- 跨层调用关系复杂。
- Skill、清单和脚本的关系复杂。
- 状态流转不适合只用文字说明。
- 需要向团队解释审查流程。

## 执行规则

1. 先读取实际存在的文件、主 Skill 路由和已验证脚本，再确定图中的节点与连线。
2. 默认输出 Mermaid；支持 flowchart、sequenceDiagram、stateDiagram-v2 和 graph。
3. 当前环境存在 visualize 时，可将其作为图形化增强能力使用；不可用时直接输出 Mermaid。
4. 图中只能使用仓库中真实存在的文件、Skill、清单和已验证路由。
5. 不确定的关系必须标记为“待确认”，不得用推测补全为确定事实。
6. 图形不能替代文件位置、代码证据、验证结果和风险说明，应在图后补充这些内容。

## 输出要求

~~~text
图类型：
图中事实依据：
待确认关系：
验证结果：
未覆盖项和已知风险：
~~~

## 边界

- Mermaid 是默认兜底，不依赖 visualize 或其他外部 Skill。
- 不为图形展示新增虚构的节点、路由或状态。
- 图形化结果只补充 fullstack-review 的解释和交付，不替代主流程、专业子 Skill 或清单门禁。

## 完成条件和回退

完成图形化输出后，返回 fullstack-review 主流程继续报告事实依据、验证结果、未覆盖项和已知风险。
